# MivChat — Real-Time Messaging Platform

- Status: Live Production
- Repository: https://github.com/realashuuu/MivChat
- Live Demo: https://miv-chat-vert.vercel.app/
- Author: Ashik Khan
- Stack: React.js, Vite, Tailwind CSS, Node.js, Express.js, MongoDB, Mongoose, Socket.IO, JWT, bcryptjs, Cloudinary CDN.

## Overview
A full-stack MERN real-time messaging platform enabling sub-50ms instant text communication, active user presence detection, image sharing via Cloudinary CDN, and read receipt tracking.

## Architecture
Client (React/Vite) ↔ Socket.IO Persistent WebSocket Handshake ↔ Express Server ↔ MongoDB Atlas Document Storage + Cloudinary Media Pipeline.
